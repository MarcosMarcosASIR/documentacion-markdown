# Documentación técnica de Linux

## Administración básica de un sistema Linux

Linux es un sistema operativo utilizado en servidores, equipos personales y entornos profesionales. En esta documentación aprenderemos conceptos básicos de administración de sistemas y organización de archivos.

La administración de Linux requiere **organización**, documentación *clara* y el uso de comandos como `ls`, que permite consultar el contenido de un directorio.

### 1. Comandos básicos

El siguiente bloque muestra algunos comandos habituales de Linux:

```bash
# Mostrar el directorio actual
pwd

# Listar archivos y carpetas
ls -la

# Consultar el usuario actual
whoami

# Mostrar el espacio disponible
df -h
```

### 2. Pasos para trabajar con Linux

1. Abrir un terminal.
2. Consultar el directorio de trabajo.
3. Ejecutar los comandos necesarios.
4. Comprobar los resultados obtenidos.

### 3. Herramientas y conceptos importantes

- **Terminal:** permite ejecutar comandos.
- **Directorios:** organizan los archivos.
- **Permisos:** controlan el acceso a los recursos.
- **Documentación:** facilita el mantenimiento de los sistemas.
